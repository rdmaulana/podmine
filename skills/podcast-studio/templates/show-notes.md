# Show notes template

Fill this in. Delete nothing the listener needs; delete everything else.

```markdown
# <Episode title>

<One sentence: what this episode is about.>

<One sentence: the single takeaway a listener could repeat to a colleague.>

## Chapters

1. <Section title> — <what is covered, one clause>
2. ...

## Sources

- <Title> — <URL or "provided by the user">
- ...

## Credits

Hosts voiced with ElevenLabs. Script and edit by <user or "you">.
```

Rules:

- Chapters describe content, not timestamps, unless you actually have timings. If you have them, format `12:34 — Section title`.
- Every claim that came from a source is listed in Sources. If the episode has no external source, write `No external source; built from the user's topic.`
- Drop the Credits section if the user does not want it.
